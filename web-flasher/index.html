WT32-SC01-PLUS Lab Web Flasher

Browser-based hardware validation for the Panlee WT32-SC01-PLUS / ESP32-S3.

Before flashing

This replaces the firmware currently stored on the board. Keep a backup of any factory image you want to restore. Use a desktop Chromium-based browser (Chrome or Edge), a data-capable USB cable, and close Arduino/PlatformIO serial monitors before connecting.

This page targets the validated lab profile Panlee ZX3D50CE08S-V15-USRC. Other OEM revisions may use different hardware.
