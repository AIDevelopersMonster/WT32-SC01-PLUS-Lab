# Hardware images

Board photographs are stored per physical specimen. The first specimen is:

- `panlee-v15-230208-sample-a/` — Panlee `ZX3D50CE08S-V15-USRC`, date/lot marking `230208`.

## Photo naming rule

- `PH01...PH99` — original/raw photographs. Never edit or overwrite these images.
- `PH01A...` — annotated/derived copies made from a raw photograph.
- If an uploaded image arrives with an arbitrary camera filename, identify it by visible content and rename it to the matching canonical `PHxx` slot.
- When a genuinely new view is supplied, allocate the next unused `PHxx` number instead of reusing a slot.

See the specimen README for the current photo manifest and placeholders.
