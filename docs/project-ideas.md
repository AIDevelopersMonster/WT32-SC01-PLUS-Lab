# Project ideas

After hardware acceptance, the WT32-SC01-PLUS can be explored as a compact human-machine-interface platform. Candidate projects:

- LVGL control panel;
- Wi-Fi/MQTT/Home Assistant terminal;
- greenhouse or workshop controller UI;
- sensor dashboard;
- network diagnostics screen;
- local device configuration console;
- ESP-NOW control panel;
- audio/status terminal if the board audio path is confirmed;
- portable test instrument front panel;
- serial/I2C/UART peripheral inspector;
- agent/AI appliance front panel connected to a stronger host or service.

Projects should reuse the verified board support layer rather than embedding guessed pin definitions independently.
