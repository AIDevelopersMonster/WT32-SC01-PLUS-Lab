# Board passports

Each physical board gets a passport. Suggested specimen ID:

`panlee-v15-230208-sample-a`

A passport should record:

- product label;
- manufacturer/OEM marking;
- PCB code and revision;
- date/lot markings;
- major IC markings;
- display/touch flex markings;
- connector labels;
- photographs/evidence references;
- acceptance stage status.

Never merge two specimens into one passport just because both were sold as WT32-SC01-PLUS.
