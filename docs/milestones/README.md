# Milestones

- **M0 — Repository bootstrap:** structure, specimen identity, acceptance rules.
- **M1 — Hardware identity:** MCU, memory, PCB/component atlas.
- **M2 — Human interface:** display, backlight and touch.
- **M3 — Peripherals:** storage, audio, USB/serial, expansion.
- **M4 — Connectivity:** Wi-Fi/BLE and coexistence.
- **M5 — Integrated BSP:** reusable board library and diagnostic application.
- **M6 — Applications:** LVGL and project demonstrations.
