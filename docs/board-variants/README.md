# WT32-SC01-PLUS board variants

This directory tracks differences between manufacturers, PCB revisions and display/touch assemblies sold under the WT32-SC01-PLUS name.

The first tracked variant is **Panlee / ZX3D50CE08S-V15-USRC / 230208**.

A difference should be recorded when it can affect firmware, flashing, electrical safety, display/touch initialization, connector mapping or mechanical integration.
